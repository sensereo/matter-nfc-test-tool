# Security policy

## Supported versions

Verified on 2026-11-06: no software versions have been released from this
repository. A supported-version policy will be established with the first
release.

## Reporting a vulnerability

Do not disclose vulnerabilities, exploit details, or credentials in public
issues or pull requests.

If the repository's GitHub Security tab offers **Report a vulnerability**, use
that private channel. Otherwise, contact a maintainer through a private contact
method explicitly listed on their GitHub profile. If neither is available,
open an issue requesting a private security contact without including details
of the vulnerability.

Include the affected revision, impact, reproduction steps, and a minimal
sanitized example in the private report. Never include live secrets or data
from devices and networks you are not authorized to test.

## Before public release

Maintainers should enable GitHub private vulnerability reporting or publish a
verified private security contact, and update this document accordingly.
