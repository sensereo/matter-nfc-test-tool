# Matter NFC Test Tool

An open-source project for a developer tool to test Matter communication over NFC.

## Project status

Verified on 2026-11-06: this repository contains the project foundation only.
Application source code, build instructions, supported hardware, and validated
workflows have not been published here yet. There is no runnable release.

The intended direction is an iOS tool for exploring NFC transport, Matter
commissioning, and device diagnostics. These are planned capabilities, not claims
of implemented functionality or device compatibility.
